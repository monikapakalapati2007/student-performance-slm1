# Student Performance Prediction using Machine Learning

## Project Overview
This project focuses on student performance
data preprocessing using Python and Machine Learning.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Hugging Face Datasets

## Dataset
The processed dataset is divided into:
- Training dataset
- Validation dataset
- Testing dataset

## Dataset Format
All datasets are stored in Parquet format.
